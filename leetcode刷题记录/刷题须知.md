## 1.算法复杂度
输入数据的形式对程序运算时间是有很大影响的，在数据本来有序的情况下时间复杂度是$O(n)$，但如果数据是逆序的话，插入排序的时间复杂度就是$O(n^2)$，也就对于所有输入情况来说，最坏是 $O(n^2)$ 的时间复杂度，所以称插入排序的时间复杂度为$O(n^2)$。

同样的同理再看一下快速排序，都知道快速排序是$O(nlogn)$，但是当数据已经有序情况下，快速排序的时间复杂度是$O(n^2)$ 的，所以严格从大O的定义来讲，快速排序的时间复杂度应该是$O(n^2)$。

但是我们依然说快速排序是$O(nlogn)$的时间复杂度，这个就是业内的一个默认规定，这里说的O代表的就是一般情况，而不是严格的上界。

在决定使用哪些算法的时候，不是时间复杂越低的越好（因为简化后的时间复杂度忽略了常数项等等），要考虑数据规模，如果数据规模很小甚至可以用$O(n^2)$的算法比$O(n)$的更合适（在有常数项的时候）。

时间复杂度的主定理
主定理（Master Theorem） 是算法分析中用来求解分治算法时间复杂度递推式的一个常用工具。它可以直接给出形如：

$T(n)=aT(n/b)+f(n)
$
的递推式的渐近复杂度，而不需要手动展开递归树或使用代入法。

其中a为子问题的个数，b为子问题规模缩小比例，$f(n)$为分解和合并子问题的额外代价

具体计算需要考虑合并部分和递归部分谁占主导


## 2.算法为什么会超出时间
我们可以假定leetcode上程序运行时间不超过一秒，那我们就可以探究一下到底怎么样才能不超时？

计算机的运算速度主要看CPU的配置，以2015年MacPro为例，CPU配置：2.7 GHz Dual-Core Intel Core i5 。

也就是 2.7 GHz 奔腾双核，i5处理器，GHz是指什么呢，1Hz = 1/s，1Hz 是CPU的一次脉冲（可以理解为一次改变状态，也叫时钟周期），称之为为赫兹，那么1GHz等于多少赫兹呢

- 1GHz（兆赫）= 1000MHz（兆赫）
- 1MHz（兆赫）= 1百万赫兹

所以 1GHz = 10亿Hz，表示CPU可以一秒脉冲10亿次（有10亿个时钟周期），这里不要简单理解一个时钟周期就是一次CPU运算。

>例如1 + 2 = 3，cpu要执行四次才能完整这个操作，步骤一：把1放入寄存器，步骤二：把2放入寄存器，步骤三：做加法，步骤四：保存3。(注：cpu不能直接在内存里面计算，要把数据放到最近的工作台来操作，这个工作台就是寄存器)

而且计算机的cpu也不会只运行我们自己写的程序上，同时cpu也要执行计算机的各种进程任务等等，我们的程序仅仅是其中的一个进程而已。

所以我们的程序在计算机上究竟1s真正能执行多少次操作呢？

在写测试程序测1s内处理多大数量级数据的时候，有三点需要注意：

- CPU执行每条指令所需的时间实际上并不相同，例如CPU执行加法和乘法操作的耗时实际上都是不一样的。
- 现在大多计算机系统的内存管理都有缓存技术，所以频繁访问相同地址的数据和访问不相邻元素所需的时间也是不同的。
- 计算机同时运行多个程序，每个程序里还有不同的进程线程在抢占资源。

尽管有很多因素影响，但是还是可以对自己程序的运行时间有一个大体的评估的。

> 引用算法4里面的一段话：
火箭科学家需要大致知道一枚试射火箭的着陆点是在大海里还是在城市中；
医学研究者需要知道一次药物测试是会杀死还是会治愈实验对象；
所以任何开发计算机程序的软件工程师都应该能够估计这个程序的运行时间是一秒钟还是一年。

用某一台机器上跑c++程序为例，$O(n)$的算法，1s内大概计算机可以运行 $5 * (10^8)$次计算，可以推测一下 $O(n^2)$ 的算法应该1s可以处理的数量级的规模是 $5 * (10^8)$开根号。

## 4.空间复杂度分析
什么是空间复杂度呢？

是对一个算法在运行过程中占用内存空间大小的量度，记做$S(n)=O(f(n)$。

>很多同学都会混淆程序运行时内存大小和程序本身的大小。这里强调一下空间复杂度是考虑程序运行时占用内存的大小，而不是可执行文件的大小。

空间复杂度是准确算出程序运行时所占用的内存么？
不要以为空间复杂度就已经精准的掌握了程序的内存使用大小，很多因素会影响程序真正内存使用大小，例如编译器的内存对齐，编程语言容器的底层实现等等这些都会影响到程序内存的开销。所以空间复杂度是预先大体评估程序内存使用的大小。

同样在工程实践中，计算机的内存空间也不是无限的，需要工程师对软件运行时所使用的内存有一个大体评估，这都需要用到算法空间复杂度的分析。

## 6.代码的内存消耗

不同的编程语言各自的内存管理方式。

- C/C++这种内存堆空间的申请和释放完全靠自己管理
- Java 依赖JVM来做内存管理，不了解jvm内存管理的机制，很可能会因一些错误的代码写法而导致内存泄漏或内存溢出
- Python内存管理是由私有堆空间管理的，所有的python对象和数据结构都存储在私有堆空间中。程序员没有访问堆的权限，只有解释器才能操作。

例如Python万物皆对象，并且将内存操作封装的很好，所以python的基本数据类型所用的内存会要远大于存放纯数据类型所占的内存，例如，我们都知道存储int型数据需要四个字节，但是使用Python 申请一个对象来存放数据的话，所用空间要远大于四个字节。Pyhon用额外的内存和性能开销换来了灵活性

而在C++中，既有对象，也有不是对象的，比如基本类型（int）、指针、数组
