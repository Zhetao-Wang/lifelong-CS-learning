先转为set，它是一个哈希表，还能去重复，

最核心的是快速查找，复杂度O(1)
而列表的查找速度是O（n）

举个例子，比如说我要查找3
列表需要逐个去对比，而哈希表直接计算3的哈希值，比如算出来5，直接去到第五个位置，然后直接对比是不是3就可以了

第二个核心思路就是使用“后面的链条只会更短”使得每个元素最多被访问两次

还有一个小trick是 如果已经得到一个长度为$n/2$的序列，则可以提早结束了



## 完整代码

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        st = set(nums)  # 把 nums 转成哈希集合
        m = len(st)

        ans = 0
        for x in st:  # 遍历哈希集合
            if x - 1 in st:  # 如果 x 不是序列的起点，直接跳过
                continue
            # x 是序列的起点
            y = x + 1
            while y in st:  # 不断查找下一个数是否在哈希集合中
                y += 1
            # 循环结束后，y-1 是最后一个在哈希集合中的数
            ans = max(ans, y - x)  # 从 x 到 y-1 一共 y-x 个数
            if ans * 2 >= m:
                break
        return ans
```
